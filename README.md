# Сайт викторин

Страница, на которой выпуск собирается целиком с телефона: вопросы,
проверка картинок, сборка и скачивание готового ролика. Домашний
компьютер для этого больше не нужен.

**Адрес: https://gallxxxx.github.io/quiz/**

## Как это устроено

Три шага на странице:

1. **Вопросы** — заставка, пары, ползунок процентов, настройки
   (фотографии или клипы, план съёмки, голос диктора).
2. **Картинки** — для каждой подписи страница сама спрашивает Pexels,
   Openverse и показывает варианты сеткой. Что выбрали — то и встанет
   в кадр. Можно поставить своё фото с телефона. Что не выбрали —
   подберётся само при сборке.
3. **Сборка** — выпуск уезжает на машину GitHub, там собирается ролик,
   и страница даёт ссылку на готовый MP4.

## Два репозитория

| Где | Что лежит | Видно ли всем |
|---|---|---|
| `gallxxxx/tiktok-quiz` | исходники проекта, сценарий сборки, задания с вопросами и своими фотографиями | нет, закрытый |
| `gallxxxx/quiz` | эта страница и готовые ролики (релизами) | да, открытый |

Разделение не случайное. Свои фотографии и черновики вопросов —
личное, они остаются в закрытом. Наружу выходит только то, что и так
пойдёт в TikTok: собранный ролик. А открытым он должен быть, чтобы
телефон качал файл обычной ссылкой, без входа в GitHub.

## Что нужно вписать один раз

На странице есть «Настройки доступа». Там два поля, и оба хранятся
только в этом телефоне — в репозитории их нет:

- **ключ Pexels** — чтобы искать картинки. Без него остаётся Openverse:
  работает, но находит заметно хуже.
- **токен GitHub** — чтобы отправлять выпуск на сборку. Без него
  страница умеет только отдать выпуск файлом, и дальше его несут
  на компьютер, как раньше.

Кнопка «Забыть всё» стирает оба.

## Секреты на стороне сборки

В закрытом репозитории, Settings → Secrets and variables → Actions:

- `PEXELS_KEY` — тот же ключ Pexels. Нужен, только если картинки
  не одобрены на сайте и их приходится подбирать на месте.
- `RELEASE_TOKEN` — токен с правом записи в `gallxxxx/quiz`. Без него
  ролик соберётся, но останется артефактом, который с телефона не взять.

Если какого-то секрета нет, сборка не падает — она пишет предупреждение
и делает, что может.

## Как выложить новую версию страницы

Весь сайт — один файл `index.html`, без сборки и зависимостей.

```
git -C "путь к папке" add index.html
git -C "путь к папке" commit -m "что поменял"
git -C "путь к папке" push
```

Через минуту-две адрес отдаёт новую версию.

## Формат файла выпуска

```json
{
  "формат": "this-or-that",
  "версия": 2,
  "заставка": { "фраза": "...", "тема": "..." },
  "концовка": { "заголовок": "...", "подпись": "...", "призыв": "..." },
  "вопросы": [
    { "сверху": "Pizza", "снизу": "Burger", "процент": 47,
      "фото": { "сверху": null, "снизу": { "имя": "x.jpg", "данные": "base64" } },
      "картинки": {
        "сверху": { "ссылка": "https://…", "вид": "фото",
                    "автор": "…", "источник": "Pexels", "страница": "https://…" },
        "снизу": null
      },
      "страны": { "сверху": "Italy", "снизу": "" }
    }
  ],
  "настройки": { "картинки": "фото", "план": "крупный",
                 "озвучка": true, "голос": "en-US-GuyNeural" }
}
```

- **`фото`** — своя фотография, ужатая браузером до квадрата 1000×1000.
  Главнее всего остального.
- **`картинки`** — то, что одобрили на сайте. Приёмник качает ровно эту
  ссылку и не ищет заново: иначе приедет другое и проверка потеряет смысл.
- **`страны`** — плашка в углу картинки. Пусто — плашки нет. Страна
  берётся только отсюда: раньше она доставалась от прошлого выпуска
  по наследству, и в кадре оказывались «Суши · Германия».

Принимает `quiz/tools/import-episode.mjs`, он же кнопка «Забрать выпуск
с сайта» дома.
