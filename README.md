# Сайт викторин

Страница, на которой выпуск собирается с телефона: вопросы, свои
фотографии, настройки. Видео она не делает — это по-прежнему делает
компьютер. Сайт отдаёт один файл `.quiz`, файл кладётся в папку
«Выпуски с сайта» рядом с кнопками, дальше кнопка «Забрать выпуск
с сайта» — и обычный конвейер.

Сейчас в списке одна викторина — «Это или то». Остальные помечены
«скоро»: структура уже рассчитана на несколько форматов, у каждого
будет свой редактор и своё значение поля `формат` в файле.

## Где он лежит

**Адрес: https://kanakovsasha-droid.github.io/tiktok-quiz/**

Репозиторий `kanakovsasha-droid/tiktok-quiz`, открытый, ветка `main`,
GitHub Pages из корня. Выложен 11 сентября 2026.

Поправить страницу = поменять `index.html` в этой папке и отправить:

```
git -C "путь к папке" add index.html
git -C "путь к папке" commit -m "что поменял"
git -C "путь к папке" push
```

Через минуту-две адрес отдаёт новую версию. Телефону может понадобиться
обновить страницу с очисткой кэша.

**Если понадобится закрытый репозиторий:** GitHub Pages из закрытого
репозитория требует платного тарифа. Бесплатный обходной путь —
Cloudflare Pages: он умеет публиковать из закрытого репозитория
на бесплатном тарифе. Подключение: dash.cloudflare.com → Workers
and Pages → Create → Pages → Connect to Git.

Прятать в репозитории, по сути, нечего: выпуски там не хранятся,
они скачиваются файлом на телефон. В коде страницы нет ни ключей,
ни паролей.

## Формат файла выпуска

```json
{
  "формат": "this-or-that",
  "версия": 1,
  "заставка": { "фраза": "...", "тема": "..." },
  "концовка": { "заголовок": "...", "подпись": "...", "призыв": "..." },
  "вопросы": [
    { "сверху": "Pizza", "снизу": "Burger", "процент": 47,
      "фото": { "сверху": null, "снизу": { "имя": "x.jpg", "данные": "base64" } } }
  ],
  "настройки": { "картинки": "фото", "план": "крупный",
                 "озвучка": true, "голос": "en-US-GuyNeural" }
}
```

Фотографии ужимаются прямо в браузере до квадрата 1000×1000 — иначе
файл выпуска весил бы десятки мегабайт и его было бы неудобно пересылать.

Принимает файл `quiz/tools/import-episode.mjs` (кнопка «Забрать выпуск
с сайта»). Он же кладёт фотографии в проект и включает нужные настройки.
